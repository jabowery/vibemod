
Rust allows multiple declarations of the "same" symbol name in a file (e.g., multiple `impl Type {}` blocks; cfg-gated duplicate items; trait impls). Therefore:

1) NEVER assume a symbol name is unique.

2) When modifying Rust declarations, ALWAYS target the exact item kind and anchor:
   - Use `impl:TypeName.method_name` or `impl(TypeName).method_name` for inherent methods.
   - Use `impl:TraitName for TypeName.method_name` for trait methods.
   - Use `impl(TypeName)#[cfg(...)]...` when cfg-gated.

3) If there may be multiple matches, add an occurrence selector `@N` (1-based) OR design the change so "replace all matches" is correct.
  Oh... did I not mention that the N in @N is 1-based?  It is 1-based.

4) When adding a new method to an existing impl block, do NOT emit a bare `fn` at module scope and do NOT wrap the method in `impl Type { }`. Target `impl:TypeName.method_name` directly (vibemod will insert into the impl block).

5) Always provide COMPLETE Rust items. No partial snippets.

6) For test-only helpers, prefer:
   - `#[cfg(test)] impl TypeName { ... }`
   and target paths using `impl(TypeName)#[cfg(test)].method`.

7) Default insertion behavior:
   - New top-level declarations (fn, struct, impl, etc.) default to end of file
   - New methods in impl blocks insert at end of the impl block
   - Explicit anchors available when needed: `@append_file`, `@insert_after(ItemName)`, `@insert_before(ItemName)`

8) Targets may specify locations and qualifying with "before" or "after" indicates insertion of the declartaion rather than replacement of the associated item.  Here's the entire grammar for target designation:
GRAMMAR = Grammar(r"""
    target          = type_trait_method / type_trait / use_target / bare_use_path / module_target
    module_target   = module_path? main_target insertion_anchor?
    
    module_path     = (identifier "::")+
    
    main_target     = scoped_target / type_ns_struct / type_ns_impl_method / type_ns_impl / impl_method / impl_target / item_method / item_target
    
    scoped_target   = scope_base "." locator_expr
    scope_base      = type_ns_struct / type_ns_impl_method / type_ns_impl / impl_method / impl_target / item_method / item_target
    
    # Type namespace explicit targets
    type_ns_struct  = identifier ".struct"
    type_ns_impl    = identifier ".impl"
    type_ns_impl_method = identifier ".impl." method_name
    
    # Type::Trait syntax for trait impls (at top level to avoid module_path conflict)
    type_trait      = identifier "::" identifier !("." / "::")
    type_trait_method = identifier "::" identifier "." method_name
    
    # Use statement target: use:path or bare path::{...} or path::*
    use_target      = "use:" use_path 
    bare_use_path   = use_path_prefix "::" use_path_suffix 
    use_path_prefix = identifier ("::" identifier)*
    use_path_suffix = grouped_import / wildcard
    grouped_import  = "{" ~r"[^}]+" "}"
    wildcard        = "*"
    use_path        = ~r"[^\n@]+"
    
    # Legacy Type.method -> impl:Type.method
    item_method     = identifier "." method_name method_mods?
    
    impl_method     = impl_base "." method_name method_mods?
    impl_base       = impl_spec impl_mods?
    impl_mods       = attr_filter? occurrence?
    method_mods     = attr_filter? occurrence?
    
    impl_target     = impl_spec attr_filter? occurrence?
    impl_spec       = impl_colon / impl_paren
    impl_colon      = "impl:" type_spec
    impl_paren      = "impl(" type_spec ")"
    type_spec       = trait_impl / type_name
    trait_impl      = type_name " for " type_name
    type_name       = identifier
    method_name     = identifier
    
    item_target     = identifier attr_filter? occurrence?
    
    locator_expr    = "@" (insert_op / replace_op)
    insert_op       = insert_side (regex / statement)
    insert_side     = ("before" / "after") ":"
    replace_op      = regex
    
    regex           = "/" regex_body "/" occurrence?
    regex_body      = ~r"[^/]+"
    statement       = ~r".+"
    
    attr_filter     = "#[" attr_content "]"
    attr_content    = ~r"[^\]]+"
    
    occurrence      = "@" pos_int
    pos_int         = ~r"[0-9]+"
    
    insertion_anchor = "@" anchor_kind
    anchor_kind     = "append_file" / "append_module" / insert_ref
    insert_ref      = ("insert_before" / "insert_after") "(" identifier ")"
    
    identifier      = ~r"[a-zA-Z_][a-zA-Z0-9_]*"
""")


9) Target path normalization: You may include the declaration keyword (e.g., `fn foo()`, `struct Bar`) but the canonical form is just the name.

Output MUST be vibemod directives only.
